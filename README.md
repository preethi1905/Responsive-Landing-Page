# 🌐 Responsive Landing Page

## 📌 Project Overview

This project is a modern and fully responsive landing page developed using HTML5 and CSS3. It demonstrates responsive web design principles, ensuring an optimal viewing experience across desktops, tablets, and mobile devices. The website features a clean layout, interactive elements, and a visually appealing user interface.

## 🎯 Objective

The objective of this project is to design and develop a responsive landing page that includes:

* A responsive navigation header
* Hero section with a call-to-action button
* Features section using Flexbox
* About section
* Footer with social media links
* Mobile-friendly layout using Media Queries

## ✨ Features

* Responsive Navigation Bar
* Attractive Hero Section

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension (if not already installed).
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. View the website in your default web browser.
